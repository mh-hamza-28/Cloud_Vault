# Cloud Vault

Cloud Vault is a secure media SaaS built with Next.js, Cloudinary, Clerk, and Prisma. It allows users to upload videos, inspect compression metrics, and prepare share-ready social content from a polished dashboard.

## Tech stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS + DaisyUI
- Cloudinary
- Clerk authentication
- Prisma + Neon PostgreSQL

## Features
- Video upload and metadata tracking
- Compression and storage insight cards
- Social-share image transformation workflow
- Protected authenticated routes
- Professional landing and auth UI

## Local setup
1. Install dependencies: npm install
2. Configure environment variables in a .env file
3. Run database setup: npx prisma generate
4. Start the app: npm run dev
5. Visit http://localhost:3000

## Production workflow
- npm run build
- npm run start
